#+title: closure — capability roadmap
#+todo: TODO(t) WIP(w) | DONE(d) DROP(x)

Working agreement for autonomous sessions: work top-down, pick the
highest =TODO=, split it into small TDD cycles, flip it to =DONE= in the
same commit that finishes it. Every item must pass the test "after this
the user can ___, which they could not before" — if the blank only
names a new method, the item does not belong here. Statistics/alias
accessor methods on closure-org/store/input are done; add no more
unless a feature in the same cycle calls one. Architecture contract
lives in [[file:docs/spec.md][spec.md]] (invariants I1–I10) and [[file:docs/phases.md][phases.md]] (milestones); this
file is the fine-grained, capability-level queue between them. Blocked
on a design decision? Record it under [[*Decisions][Decisions]], pick the most
reversible option, keep moving.

* Decisions
Open questions land here as subheadings: context, options considered,
the reversible default taken, date.
** Markdown files are search-visible but not backlink sources (2026-06-13)
=.md= files join full-text search (=closure search=, both backends).
Backlinks/the id graph stay org-only: markdown has no =:ID:= drawer,
so there's no stable block id (I2) to link to or from. Read-only-
first per the vision. Reversible: adopt a md convention (e.g. an
HTML-comment id or front-matter) and index it later.
** Perf guards use std::time::Instant, not criterion (2026-06-13)
The input-lag budget and rescan-avoided "benchmarks" are plain
=#[test]= functions timing the hot path with generous thresholds
(16ms nav, 50ms fuzzy) and asserting the incremental-reload reparse
count is 0. Avoids adding criterion (a heavyweight dev-dep) to a
hermetic nix build; the guards still fail CI on a regression.
Reversible: a =benches/= dir with criterion behind a feature can be
added if finer measurement is wanted.
** Cron daemon = system cron / shell loop, not an in-process timer (2026-06-13)
=closure cron= runs one tick of due jobs (clock injectable via
=--at=). Rather than embedding a timer thread in the CLI, the daemon
is the OS scheduler: a crontab entry =* * * * * closure cron <vault>
<file>= or a =while sleep 60= loop. Keeps the kernel free of timer
plumbing and is literally cron-compatible (the vision's word).
Reversible: an in-process =--daemon= loop can wrap the same tick
later. closure-cron's Scheduler already exists for embedders who
want it.
** Command replay from history deferred (2026-06-13)
=closure history= lists/greps the journal, and journal.org is a vault
org file so the TUI already views it. True replay (re-dispatch a past
command) needs structured, machine-replayable journal entries rather
than the current human-readable text headlines. Deferred until a
command-line serialisation format is pinned; reversible — add a
=:CMD:= property to journal entries later without breaking the text
form. The queryable-history capability is delivered now.
** Notion "+" block insert = add-sibling + inline body editing (2026-06-13)
The vision's Notion "+" inserts a typed block (headline/code/table).
Rather than a bespoke block-type model, the capability is composed
from primitives already shipped: =a= inserts a sibling headline, and
=i= edits that headline's body, where code blocks and tables live as
org body text. One headline = one addressable block; richer content
nests in its body. Reversible: a dedicated typed-block insert model
can layer on later without changing the file format.
** Wasm plugins run under external wasmtime, not an embedded runtime (2026-06-12)
Embedding wasmtime/wasmer adds a heavyweight dependency to the
kernel build. Host::invoke shells out instead: =.wasm= executables
run via the =wasmtime= CLI, native executables run directly, both
behind the same manifest-declared command surface. Reversible: swap
=runner_for= for an embedded runtime behind a feature flag later.
** Dead-link locations use block ids, not line numbers (2026-06-12)
The roadmap asked for file:line. The parser is span-preserving but
DocHeadline exposes tree paths + stable ids, not byte offsets; ids
are the project's canonical locator (I2) and survive edits where
line numbers rot. =closure dead-links= therefore prints
=file<TAB>source-id<TAB>target=. Reversible: add line numbers later
by exposing headline spans from closure-org.
